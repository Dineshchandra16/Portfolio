# Dinesh Chandra Portfolio

Interactive 3D developer portfolio for **Dinesh Chandra**, a Full Stack Developer building secure, scalable MERN applications with AI-integrated features and REST API development.

## Highlights

- 3D mechanical keyboard hero built with React Three Fiber and Three.js.
- English-only portfolio content.
- Project showcase modals with links to live projects and source code.
- Responsive design with a mobile-friendly skills grid.
- Seasonal themes, smooth scroll, custom cursor, and magnetic buttons.

## Featured Projects

### StayHealthy - Full Stack Doctor Appointment System

AI-assisted doctor appointment booking platform with manual and voice-based booking.

- Live: https://stayhealthy-0wjy.onrender.com/login
- GitHub: https://github.com/Dineshchandra16/stayhealthy-mern
- Stack: MERN, MongoDB, Express.js, React.js, Node.js, JWT, Redux, Web Speech API, Gemini API, Nodemailer

### Self-Supervised Acoustic Monitoring for Biodiversity

Self-supervised deep learning system for animal and environmental sound classification.

- Project: https://colab.research.google.com/drive/1O8VSQMhtdLaNSX6T7xlJ8lm023XqU54u?usp=sharing
